# Phase 3 Voice Cloning Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Add opt-in voice cloning: when a job sets `clone=true`, extract reference clips of the original host(s) from the downloaded episodes (via diarization) and synthesize the digest in those cloned voices — with hard guardrails: opt-in only, an audible spoken disclaimer, an inaudible watermark, and clear "AI-generated synthetic" labeling. Also add a Castbox scraper fallback for RSS-less shows.

**Architecture:** Two new ports keep the ML/side-effecting pieces swappable and CPU-testable: `VoiceCloner` (diarize + extract reference clips → per-speaker `Voice`) and `Watermarker` (embed an inaudible mark). The `synth` node gains a cloning branch that builds cloned voices, prepends a spoken disclaimer segment (in a non-cloned voice), applies the watermark, and marks the output synthetic. Everything else is unchanged.

**Tech Stack:** Phase 1–2 stack, plus (in the `[gpu]` extra, lazy) `pyannote.audio` for diarization and `audioseal` for watermarking.

## Global Constraints

- **Cloning is opt-in only** (`JobOptions.clone`, default `false`). Never clone unless explicitly requested.
- **Every cloned output is labeled synthetic** (show notes + result API) and carries an **audible spoken disclaimer** as its first segment and an **inaudible watermark**.
- Do nothing that violates the law or a platform's ToS.
- New heavy deps (`pyannote.audio`, `audioseal`) live in `[gpu]` and import lazily; default tests run on CPU with fakes.
- TDD; commit per task; imperative messages, no emojis, no Claude co-authorship.

## Task 2: VoiceCloner port + fake + pyannote backend

**Files:**
- Create: `src/repodify/ports/voice_cloner.py` (`VoiceCloner` protocol + `FakeVoiceCloner`)
- Create: `src/repodify/synth/cloning.py` (`PyannoteVoiceCloner`, lazy)
- Create: `tests/unit/ports/test_voice_cloner_fake.py`

**Interfaces:**
- `class VoiceCloner(Protocol)`: `clone(audio_paths: list[Path], speaker_keys: list[str], storage: Storage, job_id: str) -> dict[str, Voice]` — returns one cloned `Voice` per requested speaker key.
- `FakeVoiceCloner`: writes a short silent WAV to `storage` at `f"{job_id}/refs/{key}.wav"` per key and returns `Voice(name=key, ref_audio_path=<local path>, ref_text=f"reference for {key}")`; records `.calls`.
- `PyannoteVoiceCloner(transcriber, hf_token)`: diarizes the episodes, picks the `len(speaker_keys)` most-talkative speakers, cuts a reference clip per speaker with ffmpeg, derives `ref_text` via the transcriber, returns the mapping. Lazy imports of `pyannote.audio`.

- Modify: `tests/unit/worker/test_compose.py`

**Interfaces / behavior:**
- In `synth_node`, when `state["options"].clone`:
  - `audio_paths = [storage.local_path(audio_key(job_id, ep)) for ep in state["selected"] if ep.guid in state["transcripts"]]`
  - `content_speakers = sorted({seg.speaker for seg in script.segments})`
  - `cloned = deps.voice_cloner.clone(audio_paths, content_speakers, storage, job_id)`
  - prepend `disclaimer_segment(settings.clone_disclaimer)` to the script
  - synthesis voices = `{**cloned, "disclaimer": deps.voices["narrator"]}`
  - after `assemble_wav`, `wav = deps.watermarker.embed(wav)`
  - `build_show_notes(..., synthetic=True, disclaimer=settings.clone_disclaimer)`
  - add artifact `kind="reference_clip"` per cloned voice
- When not cloning: unchanged (stock voices, no disclaimer, `synthetic=False`).
- `build_deps`: fake mode → `FakeVoiceCloner()`, `FakeWatermarker()`; real mode → `PyannoteVoiceCloner(transcriber, settings.hf_token)`, `AudioSealWatermarker()`.
